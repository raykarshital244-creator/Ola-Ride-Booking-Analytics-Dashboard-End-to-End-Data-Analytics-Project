# Ola Ride Booking Analytics Dashboard — End-to-End Data Analytics Project

## Project Overview

This project demonstrates an **end-to-end data analytics workflow** using Python, MySQL and Power BI, from raw ride-booking data cleaning and preparation to SQL-based business analysis and interactive dashboard development.

The objective of this project is to analyze Ola ride-booking data and provide actionable business insights into **booking performance, ride completion, cancellations, incomplete rides, vehicle demand, customer behavior, revenue, ratings and payment methods**.

## Business Problem

Ride-booking businesses generate large volumes of transactional data. However, raw booking data alone does not provide a clear understanding of operational performance.

This project converts raw ride-booking data into an interactive analytics dashboard that answers important business questions:

* How many rides were booked?
* How many rides were successfully completed?
* How many rides were canceled or incomplete?
* Which vehicle types are most frequently booked?
* Which pickup locations have the highest demand?
* When are bookings highest during the day?
* Which days have the highest booking volume?
* Which payment methods are most commonly used?
* What is the total booking revenue?
* How are customer and driver ratings performing?

## Project Workflow

### 1️⃣ Data Cleaning & Transformation — Python

* Loaded and inspected the raw ride-booking dataset.
* Checked data types and missing values.
* Removed unnecessary spaces from text fields.
* Converted numeric columns into appropriate data types.
* Validated booking values, ride distances and ratings.
* Checked duplicate and inconsistent records.
* Prepared clean data for further analysis.
